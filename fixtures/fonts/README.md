# Font fidelity fixtures

Unmodified variable TTF files from Google's official font repository, downloaded 2026-10-21. These are test assets served by the local font lab; they are not bundled into the extension. Licenses are included alongside the fonts.

- RobotoMono.ttf: https://github.com/google/fonts/blob/main/ofl/robotomono/RobotoMono%5Bwght%5D.ttf
- Lora.ttf: https://github.com/google/fonts/blob/main/ofl/lora/Lora%5Bwght%5D.ttf
- Lora-Italic.ttf: https://github.com/google/fonts/blob/main/ofl/lora/Lora-Italic%5Bwght%5D.ttf
- RobotoMono-OFL.txt and Lora-OFL.txt are the corresponding upstream OFL notices.
